# Auralume MVP Implementation Plan

> Execução: coordenador + luna_rea + luna_developer, conforme autorização explícita do usuário. Nenhum agente adicional. As subskills superpowers citadas pelo template não estão instaladas; execução nativa e os dois agentes solicitados atendem este plano sem bloquear por revisão adicional.

**Goal:** entregar um player musical local, gratuito, sem login, com executável Ubuntu x86-64 validado.

**Architecture:** modelos imutáveis, repositório SQLite, serviços independentes de metadados/recomendações/fila/fontes e adaptador libmpv. Um controlador Qt conecta UI e serviços, com extração/importação em workers e sinais para o thread principal. UI não conhece SQL, rede nem mpv.

**Tech Stack:** Python disponível (3.14.4), PySide6/Qt6, SQLite, python-mpv/libmpv, mutagen, yt-dlp, pytest, PyInstaller.

**Spec:** `AURALUME_WORKFLOW.md`, especialmente §§ 7–18.

## Global Constraints

- Não modifique o Goof Portable.
- Não execute git push sem autorização.
- Não utilize funcionalidades pagas.
- O projeto não deverá exigir login.
- Não bloqueie o thread principal da interface com operações demoradas.
- Não implemente downloads permanentes não autorizados.

## Review Focus

- Importações repetidas devem preservar favoritos/playlists e não duplicar arquivos.
- Arquivo ausente/corrompido deve apresentar erro recuperável sem inventar histórico.
- Fila vazia, término e repeat-one devem ter comportamento previsível e não entrar em loop de falhas.
- Respostas incompletas, DRM e timeout de fontes devem resultar em erro acionável.
- Aplicativo empacotado deve iniciar e reproduzir sem depender do Python da `.venv`.
